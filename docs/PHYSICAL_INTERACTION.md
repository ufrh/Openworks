# OPENWORKS — Physical material interaction (first playable integration)

## Setup

The build reads your existing `Workspace.Workbench` and its descendants named `surface`. The server automatically creates detection/collision proxies; do not place any by hand.

- Every rigid, welded, **unanchored** physical saw/file assembly must have Boolean attribute `isTool = true` on its Model or BasePart.
- Tool operation can be declared with String attribute `FabricationKind = Saw` or `FabricationKind = File`; otherwise names containing `saw`, `file`, or `filer` are recognized automatically.
- Materials generated by FORM use `isMaterial = true` and the `FORMMaterial` tag. Server-created test steel sheets are tagged with `FORMNativeStock = true`, enabling native-Part cutting and filing in this prototype.
- Tools are **never** Roblox Tool/Backpack items. The real world object is moved by physics constraints.

## Free mode

- **Short click** material: inspect with outlined selection and controllable close-up camera.
- **Short click** a tool: if exactly one material is resting on the bench, open that material and activate the tool.
- **Mouse hold (~0.25 sec) or drag past 7 pixels** on material or tool: physics pick-up.
- While carrying: **wheel** controls depth; **Shift + WASD** changes orientation; release LMB to drop.

## Inspection

- **RMB drag** orbit; **MMB drag** pan; **wheel** zoom.
- Tool list contains physical tool Models/Parts with `isTool` and `OnWorkbench`.
- Click a tool button to request the precise fabrication session.
- **ESC / Exit** restores player camera and controls. Selected material receives a thin outline.

## Manual fabrication

- Tool must have settled on the same workbench as the selected material to begin.
- **Hold LMB and move mouse sideways, then reverse** for deliberate individual strokes.
- **Shift + move mouse sideways** adjusts cutting line/filing position.
- **Q** switches cut direction between local X and Z on rectangular sheet stock.
- **RMB drag / MMB drag / wheel** control the inspection camera.
- The *same* physical saw/file assembly is moved by server-controlled physics constraints. The sheet remains unanchored, so collisions may displace it.
- Twelve meaningful stroke reversals trigger one machining operation; the old UI/equipping prototype stays removed.

## Actual material edits in this phase

For physical `Part` workpieces marked `FORMNativeStock = true`:
- Saw performs an axis-aligned straight cross-cut of rectangular stock using `SawCut.split` and FORM. Each piece becomes a separate unanchored tagged Part, preserving material color and existing velocities, and obeys the kerf.
- File performs a **simplified planar surface shave** (reduces thickness by 0.025 studs or less). This is **not yet** the arbitrary curved/edge-filing implementation of `FileShape`.

Other tagged materials can be inspected and manipulated, but the current renderer is not wired for physical mesh replacement after fabrication; unsupported edits report this without deleting anything.

## Verification caveat

These source changes have not been run in Roblox Studio. Test drag/selection, the switch into scriptable camera, tool availability, repeated hand strokes, real offcut collisions, and exit behavior. If tests reveal trouble, fix the smallest subsystem rather than restoring the old interaction stack.
