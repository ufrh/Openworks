# OPENWORKS Phase 12 — Universal Springs + Full-Component Fitting

Build: `2026.11.10.PHASE12.UNIVERSAL-SPRINGS-COMPONENT-FITS` on `dev`.
This checklist is for manual Roblox Studio execution; no in-engine test has
been claimed or completed from the GitHub connector.

## A — Any two primitives, any geometry: spring force, no automatic guide
1. Make one rectangular bar and one cylinder, different dimensions, anywhere
   within normal construction reach. Use Edit Shift+J, select the bar, then
   the cylinder. A Spring relationship should be created despite different
   shapes, widths, sizes, rotations and lack of holes.
2. Repeat between a shaft and a tube, between two UNEQUAL blocks, between
   two plates with arbitrary orientations, and between oddly offset parts.
   The result must be the SAME free-force spring relation in every case.
3. Verify each SpringConstraint has two valid attachments, orange visual,
   stiffness/damping/rest length adjustable in Simulate Properties.
4. Start Simulate. Spring force must work; orange coil and edit guide visuals
   disappear. No hidden SpringTravelGuide, PrismaticConstraint or automatic
   slider may be generated by the spring relation.
5. Explicitly author a Slider between the appropriate holes/shafts as a
   SEPARATE relationship, then add a Spring. Simulate, confirming Slide Only
   guides motion while the spring provides restoring force.
6. Group several unconnected parts as one editor component and add a Spring.
   Confirm grouping does not create physical welds; only explicitly welded
   or bolted pieces transmit spring loads as one rigid structure.
7. Undo/redo the spring; change shape/size, run and stop again. Observe Output.

## B — Whole group against whole group: the four-post platform
1. Create a bottom editor component containing a platform + 4 rods, with
   explicit physical Weld relationships to attach each rod to the platform.
2. Create the top editor component with 4 HoleBlocks or DrilledBlocks plus
   connecting structure. Explicitly Weld its constituent primitives.
3. Move the WHOLE top component near the stationary bottom group. The snap
   search should evaluate every member of both editor groups, not just the
   single rods/hole blocks under the crosshair. Cyan highlight should cover
   the stationary group and preview dots should appear on all 4 successful
   hole/rod fits. HUD must read `4 points` or equivalent.
4. Select the Slide Only relationship after alignment. This creates ONE
   primary native PrismaticConstraint with common safe travel, and four
   visualized guide fit points, not four overlapping solver constraints.
5. Confirm the actual fitted relation shows four world-space dots, a readable
   SLIDE / 4 FITS label, axial line and two travel endpoints.
6. Make the fourth rod too wide, too tilted, too short or laterally offset.
   Preview should expose a red point and reject instead of silently treating
   the assembly as a legitimate 4/4 fit.
7. Delete the whole upper group, rebuild as a different 2/2 or 3/3 layout,
   and verify the generalized fitting behavior without a preset.
8. Test the same multi-point pattern approaching the reverse direction.
9. Repeat with other assemblies nearby: the selected stationary component
   must be isolated from unrelated neighboring parts.

## C — Relationship rendering and tuning
1. Create Bearing, Slider, Cylindrical, Weld, Bolt, Gear and Spring relations.
2. Inspect color differentiation, endpoint markers, axis lines and labels.
3. Check travel limit marks for sliding/cylindrical relationships.
4. For free-form springs, coil width should use available component envelope
   width without assuming parallel flat plates. Coil remains orange.
5. While physics runs, construction-only guides and orange coil disappear.
6. Stop/undo/delete and ensure all markers clean up, with no stale parts.
7. Test first-person camera/raycast with guide cues: markers must not collide
   with geometry or prevent selecting user-built parts.
8. Set spring stiffness, damping, rest length and joint limits in Simulate
   Properties; after Apply, test live simulation behavior.

## Regression and risk
- Verify the new default for single-shaft snaps remains Rotate+Slide, not
  implicit rigid. Actual Weld is still manual.
- Check 128 primitive / 64 relation simulation caps.
- Ensure registered assembly remains editable and full assembly is simulated.
- Check multi-fit CPU usage when moving large grouped constructions.
- Capture any Luau Output error, failed step and screenshot for follow-up.
